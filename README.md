## 🚀 Proyectos destacados

### 💎 Legendaria — El integrador de POO: Sistema de Gestión de Biblioteca

**Grupo: Los NullPointerException** 🕵️‍♂️

<details>
<summary>📖 Haz click para ver la épica completa (recomendado)</summary>

Un sistema de gestión de biblioteca en Java con **arquitectura de tres capas** — el proyecto que convirtió un TP en algo que se siente a software de verdad:

```
┌─────────────────────────────────────────────────┐
│  🖥️  CAPA 3 — GUI Java Swing                    │
│      Ventanas, temas, botones redondeados       │
├─────────────────────────────────────────────────┤
│  💾  CAPA 2 — Persistencia SQLite + JDBC        │
│      Patrón DAO, conexión singleton, FKs        │
├─────────────────────────────────────────────────┤
│  ☕  CAPA 1 — Núcleo POO (consola)              │
│      Socios, libros, préstamos, sanciones       │
└─────────────────────────────────────────────────┘
```

**Qué hace de especial:**
- 🧬 Modelado con **herencia real** (`Socio` abstracta → `Docente` / `Estudiante`) y **polimorfismo** hasta el final
- 💾 **Persistencia con SQLite + JDBC**: patrón DAO con `LibroDAO`, `SocioDAO`, `PrestamoDAO` y conexión singleton
- 🛡️ **Reglas de negocio en la base**: claves foráneas restrictivas e índice parcial único que garantiza *un solo préstamo activo por ejemplar* ( level: ingeniería de datos 🔥)
- 🏅 Sistema que **premia a docentes responsables** con más días de préstamo y **bloquea a los morosos** (justicia bibliotecaria ⚖️)
- 🖥️ **GUI Swing completa** con pantalla de carga, 4 temas visuales y renderizadores propios
- 📐 Documentación seria: UML, diagrama ER, informe técnico y ficha de autoevaluación

🔗 [Ver el proyecto completo acá](https://github.com/MiltonRodx/integrador-poo) 🧾 *Grupo: "Los NullPointerException" — desde entonces, la excepción más temida fue la que más nos enseñó.*

</details>
